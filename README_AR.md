# 🚀 منصة زايت إكس ميديا (ZaitXMedia Store Platform)

> **ZaitXMedia** هي منصة إلكترونية متكاملة وعالية السرعة لشحن وتوفير الخدمات الرقمية وعملات تيك توك، تم بناؤها بأحدث التقنيات: Next.js 15 و TypeScript و Firebase Firestore و Clerk Auth و Cloudflare Workers ومحرك أتمتة Python.

---

## 🛠️ تقنيات ولغات البرمجة المستخدمة في المشروع

| المكون / التقنية | اللغة / Framework | المفهوم والدور في المشروع |
| :--- | :--- | :--- |
| **واجهة المستخدم (Frontend)** | **TypeScript / Next.js 15 (React 19)** | بناء الواجهات التفاعلية السريعة، نظام التصميم الزجاجي Modern Glassmorphism، ودعم الهواتف وأجهزة الكمبيوتر. |
| **الخادم والـ API Backend** | **TypeScript (Node.js API Routes)** | معالجة الطلبات، حساب الأسعار، استقبال الإشعارات المالية (Webhooks)، وإدارة الجلسات. |
| **محرك الأتمتة والعمليات** | **Python 3 (FastAPI & Scripts)** | حاسبة عملات تيك توك، الأتمتة السريعة، ومزامنة أسعار الصرف الحية من قاعدة البيانات. |
| **قاعدة البيانات واللحظية** | **Firebase Firestore** | تخزين بيانات المستخدمين، الطلبات، سجلات الإيداع، وإعدادات الموقع والدول. |
| **المصادقة والأمان** | **Clerk Auth + Passkeys** | تسجيل الدخول بدون كلمة سر (Passkeys)، حماية الجلسات، والمصادقة متعددة العوامل. |
| **معالجة الرسائل والشبكة** | **Cloudflare Workers (Wrangler)** | بوابات استقبال وتوجيه رسائل SMS الإيداع وتصفية الطلبات على الـ Edge. |
| **التنسيق والتصميم** | **CSS3 + TailwindCSS** | الألوان الداكنة، التنسيقات المرنة (Universal Padding)، والأنيميشن التفاعلي. |

## 🔐 بنية الحماية والأمان في المنصة

1. **مزامنة الأسعار الديناميكية من Firestore**:
   - لا توجد أي أسعار ثابتة أو قيم محددة مسبقاً داخل الكود. يتم سحب أسعار الصرف (USD, SAR, EGP, AED) ديناميكياً ولحظياً من Firestore `settings/pricing`.

2. **منع تتبع سجلات الكونسول (Console Protection)**:
   - يتم كتم وسحر مخرجات الكونسول (`console.log`, `console.info`, `console.debug`) للمستخدمين العاديين لحماية البيانات.
   - يتاح التتبع والتصحيح حصرياً لحسابات الأدمن المعتمدة (`mohamwdzaitoon242@gmail.com`).

3. **حماية وإخفاء مسارات الإدارة**:
   - مسارات لوحة الأدمن (`/admin` و `/api/admin/*`) محمية ومخفية كلياً عن الزوار والمستخدمين العاديين، مع إرجاع `404 Not Found` لأي محاولة غير مصرح بها.

4. **تشديد قواعد Firestore**:
   - حظر الكتابة المباشرة من جانب العميل على إعدادات الموقع، الأسعار، أو السجلات المالية، واقتصار التعديل على خادم الأدمن المشفر.

5. **إعداد وسائل الدفع الإجباري المخصص**:
   - تظهر للمستخدم وسائل الدفع المتوفرة لديه فقط (فودافون كاش، انستا باي، برق، التحويل البنكي) بناءً على دولته وتفضيلاته المخزنة.

## 📁 هيكل المجلدات والملفات

```
.
├── app/                      # تطبيق Next.js (الواجهات، الصافحات، والـ API)
│   ├── (store)/              # صفحات المتجر والأقسام
│   ├── account/              # الملف الشخصي ووسائل الدفع المفضلة
│   ├── admin/                # لوحة التحكم وإدارة الدول
│   ├── api/                  # مسارات API السيرفر (بوابات الدفع وجسر بايثون)
│   ├── components/           # المكونات التفاعلية (نافذة وسائل الدفع، النماذج)
│   └── lib/                  # مصفوفة سياق الأمان، العملات، والمصادقة
├── lib/                      # منطق العمل التجاري (تحويل العملات، مطابقة الرسائل)
├── python_services/          # خادم محرك بايثون المستقل (FastAPI & Scripts)
│   ├── main.py               # خادم FastAPI للربط السريع
│   ├── scripts/              # سكربتات بايثون المستقلة (tiktok_helper.py)
│   └── requirements.txt      # مكتبات بايثون
├── worker/                   # خادم Cloudflare Worker لبوابة رسائل الدفع
├── firestore.rules           # قواعد حماية واستعلامات Firestore
├── next.config.ts            # إعدادات Next.js
└── wrangler.jsonc            # إعدادات Cloudflare Worker
```

## 🚀 دليل التشغيل السريع

### 1. تثبيت الحزم:
```bash
npm install
pip install -r python_services/requirements.txt
```

### 2. تشغيل سيرفر التطوير:
```bash
npm run dev
```

### 3. تشغيل خدمة بايثون المصغرة:
```bash
uvicorn python_services.main:app --reload --port 8000
```
