## 🌟 الميزات والتطويرات الرئيسية

### 1. 🔣 محرك الرموز الديناميكية للعملات
- إظهار وتطبيق الرموز المخصصة **`£`** (الجنيه)، **`﷼`** (الريال)، و **`$`** (الدولار) في كافة شاشات الموقع والخدمات والمحفظة.
- تنسيق ثابت ومحاذي للرقم والرمز: **`45.27 ﷼`** / **`100 £`** / **`10.50 $`**.

### 2. 📍 التحقق الجغرافي الحي المباشر من الـ IP
- فحص موقع الزائر الفعلي عند تغيير الدولة عبر خدمات الجيولوجيشن (`ipapi.co` / `ip-api.com`).
- رفض التغيير فوراً في حالة عدم التطابق مع إظهار إشعار موضح:
  > `تعذر تغيير الدولة: موقعك الجغرافي الفعلي (مصر 🇪🇬) لا يطابق الدولة المختارة (السعودية 🇸🇦) 📍`

### 3. 🐍 أداة أمان وتدقيق برمجية بلغة بايثون
- سكربت فحص وتدقيق الأمان المدمج (`scripts/security_auditor.py`).
- فحص توقيعات **`HMAC SHA-256`** لرسائل الـ SMS ومنع الثغرات.
- سكربت تجهيز واستخراج البيانات النموذجية النظيفة (`scripts/reset_example_database.py`).

### 4. 👑 لوحة تحكم ملكية للأدمن (VIP Admin Panel)
- **شريط حفظ مثبت أعلى الشاشة (Sticky Top Save Bar)**: ينزل بسلاسة ولا يتداخل مع أزرار التحكم الأخرى.
- **قائمة الموبايل من الأسفل للأعلى (Bottom-to-Top Drawer)**: تفتح بسلاسة من أسفل الشاشة على الهواتف.
- **مركز التحكم السريع المقسم لعمودين واسعين**: أزرار ضخمة وسميكة فاخرة باللون الذهبي الملكي.

## 🛠️ البنية البرمجية وتقنيات المشروع

| الطبقة | التقنية | الوصف |
| :--- | :--- | :--- |
| **الواجهة الأمامية** | **Next.js 15 (React 19)** | App Router، مكونات خادم وتصفح سريع |
| **التصميم والألوان** | **Vanilla CSS + TailwindCSS** | ذهبي `#f59e0b` ، أسود ملكي `#060a12` ، أبيض `#ffffff` |
| **لغة البرمجة** | **TypeScript 5.0** | نمط صارم مع 0 أخطاء بناء |
| **الأمان والخلفية** | **Python 3.11 + Node.js** | أدوات تدقيق الأمان وفحص التوقيع المشفر |
| **قاعدة البيانات** | **Firebase Firestore** | استماع حي ومباشر للتغيرات وأسعار الصرف |
| **النشر والتوزيع** | **GitHub Pages + Vercel** | رفع وتمرير تلقائي عبر GitHub Actions |

## 🚀 دليل التشغيل والتثبيت السريع

### 1. التنزيل والتثبيت
```bash
git clone https://github.com/mohamed-zaitoon/zaitxmedia-example.git
cd zaitxmedia-example
npm install
```

### 2. تشغيل أداة فحص الأمان ببايثون
```bash
python3 scripts/security_auditor.py
```

### 3. إنشاء ملف البيانات النموذجية النظيفة
```bash
python3 scripts/reset_example_database.py
```

### 4. تشغيل خادم التطوير المحلي
```bash
npm run dev
```
